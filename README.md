# 🏬 Store Data Analysis Project

## 📌 Project Overview
The Store Data Analysis project focuses on analyzing store sales data to understand business performance, customer purchasing behavior, product trends, and revenue growth.

The objective of this project is to transform raw store data into meaningful insights using data analytics tools and create interactive dashboards to support better business decisions.

## 🎯 Project Objectives
- Analyze overall store sales and revenue.
- Identify top-performing products.
- Understand customer purchasing patterns.
- Analyze sales performance across different categories.
- Identify monthly and yearly sales trends.
- Track key performance indicators (KPIs).
- Provide actionable business insights.

## 🛠️ Tools & Technologies
- **Power BI:** Data visualization and interactive dashboards.
- **Microsoft Excel:** Data cleaning and data preparation.
- **SQL:** Data querying and analysis.
- **DAX:** Creating calculated measures and KPIs.

## 📊 Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Total Profit
- Profit Margin
- Top-Selling Products
- Monthly Sales Growth

## 📈 Dashboard Features
- Sales Performance Analysis
- Product Category Analysis
- Monthly and Yearly Sales Trends
- Top Products Analysis
- Customer Analysis
- Profit and Revenue Analysis
- Interactive Slicers and Filters

## 💡 Key Insights
This project helps businesses:
- Identify their best-selling products.
- Understand sales trends over time.
- Monitor revenue and profitability.
- Identify high-performing categories.
- Make data-driven business decisions.
